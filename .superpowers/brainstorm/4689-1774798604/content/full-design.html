Pretext Integration Design

Two features: Interactive Hero Greeting + Glitch PageTitles

Feature 1

Interactive Hero Greeting

The randomized greeting text ("What can I help with?", "Fire away.", etc.) renders on a <canvas> via Pretext instead of as a DOM element. The cursor acts as a circular obstacle — text reflows around it in real time at 60fps using layoutNextLine().

The subtitle text ("Ask about Ben's work, writing, or speaking.") also renders on the same canvas and reflows. Suggestion buttons and the chat input below remain as regular DOM elements.

Rendering

Canvas 2D with prepareWithSegments() + layoutNextLine(). Cursor position defines a circular exclusion zone. Each line's available width is reduced where the circle intersects.

Performance

prepare() runs once on load. layoutNextLine() runs per frame on mousemove — ~0.07ms per call, well under 16ms budget. Uses requestAnimationFrame.

Font

Sohne (your site font). Greeting text at ~32px weight 300, subtitle at ~16px. Matches current design exactly.

Accessibility

Hidden <p> with sr-only class contains the greeting text for screen readers. Canvas has aria-hidden="true".

Feature 2

Glitch PageTitle

The existing terminal-style PageTitle component gains a mouse-reactive glitch effect. Each character is wrapped in a <span>. On mousemove, characters within a radius of the cursor get random CSS transforms — translate, rotate, and occasional color shifts to the terminal green or a glitch red.

The effect is subtle and contained to the title box. Characters snap back smoothly when the cursor moves away. The terminal border, ASCII art, and cursor blink animation remain unchanged.

Implementation

Pure DOM. Title text split into per-character <span> elements via client-side JS. Mousemove listener calculates distance from cursor to each character's position.

Glitch Effect

Characters within radius get: translate(Xpx, Ypx) with random jitter, rotate(Ndeg), and random color from [green, red, original]. Intensity scales inversely with distance.

Transitions

Fast in (80ms ease), smooth out (200ms ease). Characters return to their original position when cursor leaves. No cumulative drift.

Mobile

Glitch effect disabled on touch devices (no persistent cursor). Falls back to the existing static terminal title. Hero canvas also falls back to static text on mobile.
