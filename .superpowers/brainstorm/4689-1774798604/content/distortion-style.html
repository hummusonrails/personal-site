How should text react to the cursor?

Think about the ukint-vs header effect and the Pretext orb demo — what kind of distortion feels right for your site?

A

Repel / Push Away

Text flows around the cursor like water parting around a stone. Lines shrink where the cursor is, creating a circular void that text wraps around. This is the classic Pretext orb demo effect — the cursor acts as an invisible obstacle.

B

Attract / Gravitational Pull

The inverse — text characters subtly drift toward the cursor as if attracted by gravity. Lines near the cursor get wider/denser while distant lines thin out. Creates a magnetic, alive feeling.

C

Column / Magazine Flow

Text reflows into dynamic columns as the cursor moves — like the Situational Awareness demo. Moving the cursor left/right shifts where the column break happens, creating a living editorial layout. Feels sophisticated and editorial.

D

Hybrid: Repel + Shape

The cursor creates a void (like option A), but instead of a circle, the exclusion zone is shaped — like a soft rounded rectangle or organic blob that shifts as you move. Text reflows around this dynamic shape. Most similar to the ukint-vs header effect you loved.
